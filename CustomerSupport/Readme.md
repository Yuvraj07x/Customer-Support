# Customer Support NLP

A machine learning project that classifies customer support tickets into different categories using Natural Language Processing (NLP).

## Features

- Text preprocessing
- Ticket classification
- Automated responses
- Streamlit web app
- Model evaluation

## Categories

- Delivery
- Refund
- Payment
- Product Issue
- Account
- Order Cancellation
- Technical Support

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
